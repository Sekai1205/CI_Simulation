# かたつむり MIDI（GarageBand 用）

JVS-MuSiC の `modified_grouped.wav`（歌声）と**同じ旋律・タイミング・調**の MIDI。
`cisim.write_katatsumuri_midi()` で生成。中身は `cisim.katatsumuri_notes()` と同一。

## 基本情報
- テンポ：**150 BPM**（四分音符 = 0.4 秒）、4/4拍子
- 歌い出し：曲頭から **2.41 秒**（MIDIにも無音として入っている）
- 構成：3フレーズ（各12拍）× 2番、全長 約31.2 秒
- 旋律は楽譜のドレミ表記と歌声7名分の実測ピッチを照合して決定（78音中76音が歌声と半音以内で一致）

## ファイルと調（「ド」と「ソ」の音名）
| ファイル | 対応する歌声グループ | ド | ソ |
|---|---|---|---|
| katatsumuri_m_low.mid | m_low | A#2 | F3 |
| katatsumuri_m_mid.mid | m_mid | C#3 | G#3 |
| katatsumuri_m_high.mid | m_high | D#3 | A#3 |
| katatsumuri_f_low.mid | f_low | A3 | E4 |
| katatsumuri_f_mid.mid | f_mid | A#3 | F4 |
| katatsumuri_f_high.mid | f_high | C#4 | G#4 |

## GarageBand での手順
1. 新規プロジェクト → **テンポ 150**、拍子 4/4 にする（MIDIを読み込むと自動で合う場合もある）
2. `.mid` ファイルをトラック領域にドラッグ＆ドロップ → ソフトウェア音源トラックができる
3. 音源を選ぶ（例：Grand Piano、Flute、Violin）
4. **エフェクトを全部オフ**：トラックのプラグイン（リバーブ・コンプ・EQ）と、マスタートラックのエフェクトの両方
5. 書き出し：「共有」→「曲をディスクに書き出す」→ **WAV / 非圧縮**。曲頭の無音（2.41秒）は削らない
6. `data/music_inst/` に `katatsumuri_gb_<楽器>_<グループ>.wav` のような名前で保存
